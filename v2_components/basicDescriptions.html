basicDescriptions 组件 ​

基于 ElementUI Descriptions 封装的描述列表组件，支持动态配置、自定义渲染、多组数据显示等功能

示例 ​

vue
<template>
  <BasicDescriptions v-bind="{ schemas: schemas, value: meeting, border: true, column: 2 }" />
</template>
<script>
import BasicDescriptions from '@/components/BasicDescriptions';
export default {
  components: { BasicDescriptions },
  data() {
    return {
      schemas: [{ label: '会议名称', field: 'meetingName' }],
    };
  },
};
</script>

属性说明 ​

属性名类型默认值说明
schemasArray-列表项配置
valueObject｜Array-显示的数据
labelWidthString'170px'标签宽度

Schema 配置项 ​

属性名类型默认值说明
labelString-标签文本
fieldString-字段名（支持嵌套路径）
componentComponentType-自定义组件
componentPropsObject-组件属性
spanNumber1占据的列数
renderFunction-自定义渲染函数
ifShowBoolean｜Functiontrue是否显示

ComponentType

ts
type ComponentType = 'File' | 'ApiTree' | 'Select' | 'BasicDescriptions' | 'UploadFile';

注意事项 ​

  1. field 支持嵌套路径如 user.name
  2. 通过 render 函数可自定义显示内容
  3. component 可指定自定义组件显示复杂内容
  4. ifShow 支持函数动态控制显示
  5. 自动处理数组数据展示多组信息
