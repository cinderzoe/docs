RegisterForm 表单组件库使用说明 ​

功能概述 ​

提供动态表单渲染、数据绑定、状态管理等功能，支持多种表单组件类型和表格明细表。

安装与引入 ​

javascript
import { RegisterForm } from './registerForm.js';

或 引入 <script src ="/js/essex/basicFormApi.js"></script> 文件, 再调用

javascript
const { RegisterForm } = window.BasicFormApi;

基础用法 ​

1. 初始化表单 ​

javascript
const schemas = [
  {
    field: 'username',
    component: 'Input',
    label: '用户名',
    required: true,
  },
  {
    field: 'dt1',
    component: 'Table',
    schemas: [
      {
        field: 'product',
        component: 'Browser',
      },
    ],
  },
];

const BasicForm = new RegisterForm(schemas);

2. 获取表单数据 ​

javascript
const formData = BasicForm.getFieldsValue();

3. 设置表单值 ​

javascript
BasicForm.setFieldsValue({
  username: '张三',
  dt1: [{ product: { value: 'p001', title: '商品1' } }],
});

注：如果给明细表设置，没有在对象里设置 rowIndex,则按从上往下的顺序填充值，如果设置了 rowIndex，则更新对应 rowIndex 的行

示例：

javascript
//对应更新明细表dt1的第一行的数据
BasicForm.setFieldsValue({
  username: '张三',
  dt1: [{ product: { value: 'p001', title: '商品1' } }],
});

//对应更新明细表dt1 里面行属性_rowindex="2" 的该行的数据
BasicForm.setFieldsValue({
  username: '张三',
  dt1: [{ product: { value: 'p001', title: '商品1' }, rowIndex: 2 }],
});

Schema 配置说明 ​

属性名类型必填默认值说明
fieldstring是-字段标识名，需保持唯一
componentstring是-组件类型，可选值见下方组件类型表
defaultValueany/Function否-默认值，支持函数动态返回 (modal,value,row)=>value, row 为同行对象， 为明细表专属字段
ifShowboolean/Function否true是否显示，函数形式为 (modal,value,row)=>boolean
readonlyboolean/Function否false是否只读，函数形式为 (modal,value,row)=>boolean
requiredboolean/Function否false是否必填，函数形式为 (modal,value,row)=>boolean
onChangeFunction否-值变更回调 ({field,value,setFieldsValue})=>void
schemasArray仅 Table 类型需要-明细表格的子字段配置
customRenderFunction否-自定义渲染函数 (schema,tableIdx,rowIndex)=>HTMLElement

注意：1、表格类型(Table)必须包含嵌套的 schemas 定义子字段 2、readonly 方法的 row 是明细表属性才有的参数，为同行数据属性

组件类型支持 ​

类型说明数据类型
Input普通输入框string
Browser浏览框{value, title}
Text文本,存在{value, title}的这种设置情况，是显示值和 value 不一致的情况下的处理{value, title}/string
Table明细表格Array
FileUpload文件上传string(JSON)

FileUpload 的类型 JSON 为 上传到 oss 后的返回值，例如[{"name":"upload/20250612/055aa6c3e463af7576a9896ed315a37b.jpg","originalName":"一等座291.jpg"}]

核心 API ​

RegisterForm 类 ​

构造函数 ​

javascript
new RegisterForm(schemas: Array<Schema>)

方法 ​

  • getFieldsValue(): 获取整个表单数据
  • setFieldsValue(values: Object): 批量设置表单值
  • clearFieldsValue(fields: string|Array): 清空指定字段

辅助函数 ​

表格操作 ​

javascript
setTableFieldsValue(
  tableIdx: number,
  rowIndex: number,
  field: string,
  value: any,
  component?: string
)

列显示控制 ​

javascript
setTableColVisible(
  tableIdx: number,
  fields: Array<string>,
  visible: boolean
)

最佳实践 ​

1. 动态控制字段显示 ​

javascript
{
  field: 'approveAmount',
  ifShow: (modal) => modal.amount > 10000
}

2. 自定义组件渲染 ​

javascript
{
  field: 'custom',
  customRender: () => $('<div class="custom-comp">')
}

注意事项 ​

  1. 表格组件必须包含schemas属性
  2. 浏览器类组件需要使用{value, title}格式数据
  3. 私有方法以#开头，不要直接调用
  4. 通过ifShow隐藏的属性值都会被清空，显示则恢复原来的值
