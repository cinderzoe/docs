useFetch ​

用于异步数据获取的组合式函数，支持：

  • 基础数据请求
  • 分页数据全量加载
  • 请求前后钩子
  • 数据匹配功能
  • 确认弹窗控制

示例 ​

基础用法 ​

javascript
const { data, loaded } = useFetch({
  api: fetchUserList,
  immediate: true,
});

带参数请求 ​

javascript
const { fetch } = useFetch({
  api: fetchUserList,
  params: { pageSize: 10 },
});

// 手动触发
fetch({ pageNum: 2 });

分页全量加载 ​

javascript
const { data } = useFetch({
  api: fetchUserList,
  fetchAll: true,
});

数据匹配 ​

javascript
const { match } = useFetch({
  api: fetchOptions,
  labelField: 'name',
  valueField: 'id',
});

// 匹配单个值
match(1); // => '选项1'

// 匹配多个值
match([1, 2]); // => ['选项1', '选项2']

请求钩子 ​

javascript
useFetch({
  api: fetchData,
  beforeFetch: async () => {
    // 返回的参数会合并到请求参数中
    return { extraParam: 'value' };
  },
  afterFetch: (data, params) => {
    console.log('请求完成', data, params);
  },
});

确认弹窗 ​

javascript
const { fetch } = useFetch({
  api: deleteItem,
  showModal: true,
  modalTitle: '确认删除?',
});

Props ​

属性类型默认值说明
apiFunction-必填，请求函数
paramsObject | Function-请求参数
resultFieldstring-响应数据中结果的字段名
labelFieldstring-数据项标签字段名
valueFieldstring-数据项值字段名
immediatebooleanfalse是否立即执行
beforeFetchFunction-请求前钩子
afterFetchFunction-请求后钩子
showModalbooleanfalse是否显示确认弹窗
modalTitlestring-弹窗标题
fetchAllbooleanfalse是否加载全部分页数据
defaultValueany-默认值

Methods ​

属性类型说明
dataRef<any>响应式数据
loadedRef<boolean>加载状态
matchFunction数据匹配方法
fetchFunction手动触发请求

方法说明 ​

fetch(extraParams?: Recordable) ​

手动触发请求

match(val: any) ​

数据匹配方法：

  • 当 val 为数组时，返回匹配项的 label 数组
  • 当 val 为单值时，返回匹配项的 label 字符串

注意事项 ​

  1. api 函数需要返回包含 success 和 data 字段的对象
  2. 当 fetchAll=true 时，响应数据需要包含分页信息 pages 和 current
  3. beforeFetch 返回 false 值会中止请求
